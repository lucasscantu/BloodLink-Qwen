# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2024-06-15

### Added
- Sistema completo de rastreabilidade de bolsas de sangue
- Frontend React + TypeScript + Tailwind CSS
- Backend Node.js + Express + Prisma + PostgreSQL
- Blockchain Hardhat + Solidity (contrato append-only)
- QR Code (geração e escaneamento)
- Dashboard com gráficos (Recharts)
- Gestão de bolsas com máquina de estados
- Demandas e transferências entre instituições
- Monitoramento de temperatura com alertas
- Auditoria completa
- RBAC com 4 perfis (ADMIN, HEMOCENTRO, HOSPITAL, AUDITOR)
- Docker Compose com 4 serviços
- Documentação completa
- Testes nas três camadas (frontend, backend, blockchain)
- 13 correções de bugs identificados em rodada anterior
